# IBD-proteomics

This repository for analysis code of proteomics data in human PBMC of healthy control and Crohn's disease.

If you have any questions, feel free to contact Fan Wu (fanwu1213@zju.edu.cn) or Francis K-M Chan (fkmchan@zju.edu.cn).

## software version:
DIA-NN 1.8.1, Python 3.13.1, R 4.5.1, ComplexHeatmap 2.24.1, Metascape 3.5, clusterProfiler 4.16.0, ggplot2 4.0.1, dplyr 1.1.4, readxl 1.4.5, RColorBrewer 1.1-3, ggpubr 0.6.2, FactoMineR 2.12

If you have any questions about code, please let me know in ISSUES(https://github.com/ChanLabLZ/IBD-proteomics/issues).

Additional information is available in the Key Resources Table (see paper).
